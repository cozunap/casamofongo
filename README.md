# La Casa Del Mofongo - Coming Soon & Web Platform

Sitio web multi-página oficial para **La Casa Del Mofongo** (Manhattan, Nueva York).

## Estructura
- `index.html`: Página principal con cuenta regresiva, captura de leads VIP y pilares gastronómicos.
- `menu.html`: Adelanto de menú con especialidades (Mofongos clásicos y mariscos, rabo encendido, picaderas).
- `locations.html`: Detalles de las sedes de Inwood (Piano Bar) y Washington Heights con mapas y horarios 24/7.
- `contact.html`: Formulario de reservas, eventos y catering.
- `css/styles.css`: Sistema de diseño de lujo (Navy + Gold), tipografía Playfair Display + Inter, tokens CSS y micro-animaciones.
- `js/components.js`: Detección automática de idioma de navegador, header sticky y footer unificados, cuenta regresiva y validación de formulario.

## Despliegue en Cloudflare Pages
El sitio está configurado para desplegarse instantáneamente en Cloudflare Pages.
