# La Casa Del Mofongo - Silver Spring, Maryland

Sitio web multi-página oficial (Coming Soon & Plataforma Web) para **La Casa Del Mofongo** ubicada en **Silver Spring, Maryland (Área DMV)**.

## Información del Negocio
- **Dirección:** 9441 Georgia Ave, Silver Spring, MD 20910
- **Teléfono:** (240) 863-3750
- **Horario:** Lunes a Domingo: 11:00 AM – 10:00 PM

## Estructura
- `index.html`: Portada con cuenta regresiva, captura de emails para lanzamientos y pedidos online, pilares gastronómicos y datos de la sede.
- `menu.html`: Muestra de especialidades (Mofongo con masita de puerco, camarones al ajillo, trifongo, chicharrón, bistec encebollado y postres).
- `locations.html`: Página detallada de ubicación sobre Georgia Ave, mapa interactivo y horarios.
- `contact.html`: Formulario de reservas, pedidos especiales y catering para el DMV.
- `css/styles.css`: Sistema de tokens CSS, tipografía Playfair Display + Inter y micro-animaciones.
- `js/components.js`: Header/footer compartidos, menú responsive, cuenta regresiva y detección automática de idioma del navegador.
